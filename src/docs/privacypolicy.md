
# Privacy Policy — Project U/R

**Last Updated:** October 21, 2026

## 1. Introduction

Project U/R (Unrestricted) is an open-source, non-Chromium browser developed under the ZTL (Zeo Thinking Labs) Foundation.

U/R is designed with a privacy-first philosophy. The project aims to keep user data under the user's control and avoid unnecessary data collection, tracking, and external dependencies.

**Our principle is simple: Your data belongs to you.**

## 2. Data Collection

Project U/R does not intentionally collect personal information from its users.

The project does not require or intend to provide:

- User accounts or registration.
- Centralized user profiles.
- Telemetry or behavioral analytics.
- Advertising trackers.
- Cloud-based browsing history synchronization.
- Centralized collection of bookmarks, browsing history, or browser settings.

U/R does not operate a service that requires users to submit personal information as a condition of using the browser.

## 3. Local Data Storage

Browser data, where applicable, is intended to remain on the user's local device.

This may include:

- Bookmarks.
- Browsing history.
- Browser settings and preferences.
- Cookies and website storage.
- Downloaded files.
- Other browser-related configuration data.

Users are responsible for securing their devices and managing locally stored information. Anyone with sufficient access to the device or its files may be able to access this information.

## 4. Network Requests and Third-Party Websites

Although U/R aims not to collect user data for its own purposes, browsing the internet necessarily involves communication with external servers.

When users visit websites or use external services, those services may receive information such as:

- IP address and connection metadata.
- Browser and device information exposed by the browser.
- HTTP request headers.
- Cookies or other identifiers, where applicable.
- Information voluntarily submitted by the user.

Third-party websites operate under their own privacy policies and practices. Project U/R does not control how those services collect, process, or retain information.

**Using a privacy-focused browser does not make all internet activity anonymous.**

## 5. Telemetry and Analytics

Project U/R is intended to operate without mandatory telemetry, behavioral analytics, or centralized usage tracking.

Any future feature that introduces telemetry or external data transmission must be evaluated against the project's privacy principles and documented before release.

## 6. Accounts and Cloud Services

Project U/R does not require a centralized account to use the browser.

The project does not intend to provide mandatory cloud synchronization or centralized storage of user browsing data.

Any optional future integrations with external services must clearly document what information is transmitted and to whom.

## 7. Security and User Responsibility

Project U/R is being developed with privacy and security as design priorities. However, no software can guarantee absolute security or complete anonymity.

Users should:

- Keep their operating system and browser updated.
- Download software from trusted sources.
- Exercise caution when visiting unfamiliar websites.
- Protect access to their devices and local files.
- Avoid entering sensitive information on untrusted websites.

Security features and their limitations will depend on the implementation available in each release.

## 8. Open-Source Transparency

Project U/R is intended to be developed openly, with source code made available through its official GitHub repository.

Users and contributors are encouraged to inspect the source code, report potential privacy issues, and contribute improvements.

Open-source availability does not, by itself, constitute a security audit or guarantee that every build is free from vulnerabilities.

## 9. Children's Privacy

Project U/R does not intentionally collect personal information from children or other users.

Because the browser is designed to avoid centralized user-data collection, it does not establish a separate user profile for age-based data collection.

Parents and guardians remain responsible for supervising internet access where appropriate.

## 10. Changes to This Policy

This policy may be updated as Project U/R develops.

Material changes to the browser's data-handling practices should be reflected in this document. The latest version will be available in the project's official repository.

The date at the beginning of this document indicates when this policy was last updated.

## 11. Contact and Reporting

For questions, privacy concerns, or reports of potential data-handling issues, users may open an issue or contact the maintainers through the official Project U/R GitHub repository.

Repository: https://github.com/Zeo120/U-R

## 12. Final Statement

Project U/R is built around the principle that users should retain control over their own data.

The project aims to avoid unnecessary collection, tracking, and centralized storage while providing a transparent, open-source browser.
